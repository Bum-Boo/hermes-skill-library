# Web interface verification

Use this collection when responsive interfaces need evidence-backed debugging across viewport sizes and pointer capabilities.

## Included skills

- `responsive-touch-interface-verification` — diagnose tablet-specific breakpoint and hover/touch conflicts, apply a minimal fix, and verify rendered interactions without regressing desktop or phone behavior.

## Install

```bash
./scripts/install-collection.sh web-interface-verification
```

The workflow is framework-agnostic and favors existing DOM and interaction contracts over tablet-only redesigns.
