# Hermes Profile Operations

Use this collection to inspect and maintain multi-profile Hermes installations without exposing credentials or confusing disk state with live gateway state.

## Skills

- `hermes-profile-config-inspection` — inspect active/default configuration, tool exposure, and runtime application.
- `hermes-profile-storage-audit` — inventory profile storage and prepare approval-gated cleanup plans.
- `hermes-profile-context-diet` — reduce persistent prompt and skill weight while preserving durable knowledge.

Install:

```bash
./scripts/install-collection.sh hermes-profile-operations
```
